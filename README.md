# Lern-Quiz (PWA)

Fächer: Wirtschaft (WG1+WG2), Netzwerke, Hardware, Service & QM. Pro Fach zwei Karteien: Multiple Choice und Szenario. Eichhörnchen-Coach (coach.js): Tagesziel, Serie, Nüsse, Schwächen-Tipp. Darstellung: Hell, Dunkel, Auto.

- Neues Fach: `data-<id>.js` anlegen (FACH_DATA.<id>) und in `faecher.js` bei FACH_FILES eintragen.
- Szenarien: `data-szen-<id>.js` mit `SZEN_DATA.<id> = [{t,h,f,a,m,p:[[Punkt,[Stichwörter]]]}]` (für Wirtschaft: id `wirtschaft`).
- Bei jeder Änderung `APP_VERSION` in `faecher.js` erhöhen.
